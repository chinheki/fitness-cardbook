# 健身卡册

一个本地优先、无需账号的健身截图 PWA。原生 HTML / CSS / JavaScript，裁剪使用本地内置 Cropper.js 1.6.2（MIT），GitHub Actions 发布到 GitHub Pages。

## 使用

1. 点底部大 ＋，从相册多选同一个动作的截图；长按 ＋ 可拍照。也可在设置中进入拍照或创建纯文字卡。
2. 照片预览下点“框选裁剪”，拖动裁剪框四角调整范围、拖动框内移动选区，点“使用裁剪照片”确认；取消裁剪保留当前照片。多张照片可以分别裁剪；确认第一张后，后续裁剪可点“沿用上次比例”，锁定宽高比调整大小和位置，再点一次可解除。新标签填完后点别处或按回车自动选中，直接保存卡片也会带上标签，无需另按添加。点底部“添加”保存卡片。卡册多图每 2 秒轮播，照片完整显示。点击卡片查看原图、填写最多 10 字的名字或备注。
3. 点“随机 8 项”或“自定义”，勾选卡片；已选置顶，可增减数量或左滑取消。底部按钮固定，卡册独立滚动。
4. 点“开始”，为每项设置时间／次数、组数、休息时间。次数模式由用户手动确认完成，不自动识别动作。下一次带出上次参数，并提供粗略次数节拍参考。
5. 训练结束自动保存，历史按周与日期倒序显示。设置里可导出包含照片的 JSON 完整备份，或恢复备份。

## 添加到手机桌面

iPhone：Safari → 分享 → 添加到主屏幕。Android：浏览器菜单 → 安装应用／添加到主屏幕。首次在线打开、应用资源缓存成功后可离线使用。

相册选择与拍照的具体界面由手机浏览器决定；如果长按不方便，设置中有直接的拍照入口。浏览器后台不承诺持续声音或提示；返回后按时间戳重算，刷新时恢复到暂停状态。支持的浏览器会在训练中请求屏幕常亮。

## 数据边界

照片（裁剪后保存裁剪版本）、640px 缩略图、卡片和记录均保存在当前浏览器 IndexedDB，不发往服务器。图片名称不会作为动作名字展示。原相册文件不会修改。训练进行状态保存在本机 localStorage。

浏览器清理、存储回收或换设备会导致本地数据不可用。请定期导出完整备份，备份包含私人照片，妥善保管。恢复会先校验文件，确认后以单个事务替换当前数据。大批原图的备份需要内存和空间，建议分批收集并定期备份。HEIC 等照片是否可读取决于浏览器解码能力；不支持时会提示转换为 JPG / PNG，不会假装保存成功。

删除卡片不会清空历史引用的图片；当前版本为了保护历史保留图片资产，清空全部数据时才统一清理。当前不做账号、云同步、AI 识别、训练计划或收藏组合。

## 本地运行与测试

```sh
python3 -m http.server 4173
# 打开 http://localhost:4173
node --test tests/logic.test.js
```

直接双击文件无法获得 IndexedDB / Service Worker 的完整行为，请通过本地服务器或 HTTPS 地址使用。

## 发布

推送 main 后，`.github/workflows/pages.yml` 检查代码和核心逻辑，打包白名单里的网页资源，通过 GitHub Pages Actions 发布。首次在仓库 Settings → Pages 中选择 GitHub Actions。发布内容不包含本地照片、测试备份或工作目录。

修改离线资源后需要升级 `sw.js` 中的缓存版本。新版 Service Worker 会等旧应用窗口关闭后启用，避免训练中途切换版本。

## 文件

- `app.js`：页面与训练状态、导入／备份、系统文件选择。
- `db.js`：IndexedDB，照片和卡片原子保存。
- `logic.js`：随机选择、排序、时间、周期与备份校验。
- `style.css`：手机卡册、固定底部、训练与历史页面。
- `manifest.webmanifest` / `sw.js` / `icons/`：PWA 安装与离线缓存。

线上地址继续为 `https://chinheki.github.io/fitness-cardbook/`，源码改在非商业分支 [chinheki/openGym](https://github.com/chinheki/openGym)。本仓库 Actions 检出该分支、测试构建并部署到原地址；原生卡册源文件保留用于追溯，不再单独作为发布产物。

整合版保留原 IndexedDB 和进行中训练，在「我的卡册」直接读取，并将收藏和历史建立为 OpenGym 可识别的副本。首次在**原浏览器、原网址**打开可继承已保存存档。不同设备／浏览器／本地预览与线上不共享存储，可先在原环境导出完整 JSON，再在「我的卡册 → 设置」恢复。未保存的上传草稿需先在原标签页点“添加”，再刷新整合版。不要清理网站数据。
