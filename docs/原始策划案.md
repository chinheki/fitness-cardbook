# 健身卡册 · 最小版本策划案

日期：2026-10-10 ｜状态：v0.1 初版已开发并发布，浏览器与线上离线检查通过

**当前以第三版交互为准：卡册内随机／自定义选卡后直接准备开始，不另跳今日安排页。底部导航为设置／添加／历史。训练计划和收藏组合暂缓；下方早期构想保留作后续参考。**

## 1. 这个产品做什么
把零散的健身截图收成自己的动作卡册。练习时选几张卡，给每张卡设置次数或时长、组数，照着图片练；练完自动留下记录，喜欢的组合可以收藏并再次使用。

核心路径：收截图 → 收成动作卡 → 选今天要练的卡 → 设置并跟练 → 留下历史／收藏组合。

不注册账号，不上传照片到服务器。第一版只服务个人使用，不做社交、AI 识别、视频网站抓取或复杂训练分析。

## 2. 第一版必须能完成的事

1. **收集动作**：一张动作卡可放 1 张或多张截图，按用户指定顺序保存；支持纯文字卡、截图加备注。标题和分类均可不填，不强制生成或展示动作名；自定义名字最多 10 个字。竖屏截图完整显示，不裁掉动作或原图文字；点开可放大。截图里的文字先作为图片保留，不做 OCR。
2. **自由分类**：自建标签，例如手臂、腹部、拉伸；一张卡可以有多个标签，也可以不分类。首页是双列卡册，点标签筛选。底部“随机 8 项”从当前筛选范围随机、不重复抽取，不足 8 项则全部选入并提示；旁边“自定义”进入卡片选择模式。未选卡片变灰，选中卡片恢复清晰并显示边框和右上角勾选，无单卡“加入今日”按钮。确认后进入今日安排，可调整训练顺序、移除卡。
3. **临练再设置**：每张卡选择“按时间”或“按次数”，设置例如 60 秒 × 3 组、40 次 × 3 组，可选组间休息。第一次不要求预先录完整资料；再次选卡时直接带出最近一次使用的设置，仍可修改。
4. **照图跟练**：训练页以截图为主，多张图按顺序循环，单张图保持显示。时间模式显示倒计时；次数模式显示目标次数与已用时间，第一次由用户按“本组完成”。组数进度一直可见，提供暂停、完成本组、结束本次训练。倒计时结束会提示，但由用户确认完成后才切下一组；不强制跳走。
5. **留住有效组合**：完成后自动保存训练历史，包括动作顺序、设置、实际完成组数及耗时。中途结束记为未完成。可以把历史中的一次训练收藏、命名成组合，下次一键载入，再按当天状态调整。历史保留当时的名称和设置快照，后续改卡不改旧记录。

## 3. “下次推荐”先用最简单的方法

- 参数推荐：默认带出该动作最近一次使用的次数／时长／组数，而不是生成新的训练建议。
- 组合复用：最近训练和收藏组合都提供“再练一次”，不做复杂推荐算法。
- 次数节拍：记录每组从开始到用户按完成的有效用时，暂停与组间休息不计入。只有用户确认完成了目标次数的组才参与估算。
- 例：确认 40 次用了 80 秒，则下次提供约 2 秒／次的可选节拍。它是粗略参考，不是动作识别或自动计次；可以关闭或修改，估算计数到目标后仍等用户确认。
- 多图轮播与次数节拍分开设置；截图间隔不能直接当作一次动作的间隔。

## 4. 页面、数据与本地边界

四个主要页面：**卡册**（收集／分类／选卡）、**今日训练**（顺序与每卡参数）、**跟练**（图片／计时／组数）、**记录与组合**（历史／收藏／再次训练）。底部导航只放卡册、今日、记录；跟练时收起导航，减少误触。

本地保存：动作卡、图片文件、分类、上次参数、训练历史、收藏组合和进行中的训练状态，使用 IndexedDB；照片不转成大量字符串塞进 localStorage。导入时生成封面缩略图，原始上传文件保留，不修改手机相册中的原图。

最小数据：ActionCard、ImageAsset、Tag、WorkoutSession、SessionItem、FavoriteRoutine。训练记录引用图片资产；删除卡片时如仍被历史或组合使用，先保留资产，避免旧记录出现空图。

PWA 目标：手机浏览器直接使用，可添加到主屏幕；应用资源离线缓存，本地卡片离线可读。首次打开需要网络完成资源加载。后台时不承诺持续声音或准确触发提示，返回前台按时间戳重算；提供屏幕常亮能力时使用，不把它作为必需条件。训练中刷新能恢复到暂停状态，用户确认后继续。

本地数据只在当前设备和浏览器中。清理网站数据、换手机或浏览器存储被回收可能丢失。第一版提供手动完整备份／恢复（包含图片），不要求用户配置云服务。存储不足时保留已存内容并明确提示本次导入未完成，不能假装保存成功。

## 5. 快速交付顺序与验收

**第一步：卡册闭环。** 导入多图、纯文字卡、编辑／删除、标签、完整图预览、本地保存；刷新后卡片和图片仍存在。

**第二步：训练闭环。** 选卡、排序、设置参数、图片循环、计时／手动完成、组间休息、暂停／恢复、保存记录；完成 3 组后进度正确，中途结束不记成全部完成。

**第三步：复用与安装。** 上次参数、历史再练、收藏组合、粗略次数节拍、备份恢复、PWA 安装和离线；手机实测后才算可用。

参考工时：可操作原型约 1–2 个工作日，补齐本地备份、离线与手机验证约 1–2 个工作日；这是范围估算，实际以逐步验收为准。本轮仅交付策划案与界面印象，不把预览称为已可使用的 PWA。

UI 候选：
- **清爽卡册（建议）**：双列竖图、分类在上、选卡后底部开始。收集与训练兼顾。
- **随手翻卡**：单列大图、逐卡浏览、直接加入今日。更适合仔细看截图，翻找较慢。
- **今天就练**：首页先展示今日动作和上次组合，卡册是入口。更适合反复练固定组合。

三种方向共用同一套功能与数据，只选择默认首页和信息密度，避免做三套产品。

## 已选 UI 与第二版细节

采用“清爽卡册”。首页多图卡按顺序循环播放，暂定每 2 秒切图；单图静止。系统减少动态效果设置启用时停止自动播放。名字与分类作为标签叠在卡片左下角：名字在分类左侧，空间不足换到上一行；无名卡只显示分类。名字最多 10 个字。

双列每行对齐：有竖图时以竖图高度确定该行高度；横图按原始比例靠上、完整显示，余下空间留空，不拉伸、不裁切。纯横图行按横图内容与最低高度显示，UI 预览最低高度为 154px，正式实现随设备宽度调整。图片比例按每卡封面确定，轮播期间保持卡片尺寸稳定。

第二版预览提供 4 张示意卡，含未命名、多图、混合横竖行和纯横图行；随机抽取因此最多演示 4 项。它仅用于确认界面与交互，不保存真实图片或训练记录。

## 第三版确认方向（优先于早期页面方案）

### 卡册与随机选卡
卡片区域独立纵向滚动，底部操作区和导航始终留在屏幕底部。浏览状态显示“随机 8 项／自定义”。随机后不跳转：进入勾选状态，选中卡片置顶，未选卡片变灰，所有卡片右上角展示真实 checkbox。取消勾选的卡片回到未选区，重新勾选的卡片进入置顶区；支持左滑取消选中，不删除卡片。数量不锁定为 8，可以增减。底部变为单个大“开始”，数量为零时不可开始。自定义共用这一选择状态，从零项开始。

数据本地保存；第一版不做分页式慢加载。优先加载轻量缩略图，仅让可见卡片轮播，避免一次解码全部原图；是否增加窗口化展示以实际卡片量和设备性能决定。随机默认从当前筛选范围取最多 8 张，不足时取全部，不重复。

### 最底部导航
左侧设置，中间大圆形加号，右侧运动历史。不显示卡册或今日入口。点加号立即打开系统相册多选；长按约 550 毫秒走拍照入口，松手不再误触相册。系统取消选择不创建空卡，停留卡册。网页端相册／拍照的具体系统界面与可用能力，需要在目标手机上验证；必要时保留可直接点选的拍照备用入口。

### 添加运动
相册选完后进入添加页：中间显示一张完整照片，下面是已选照片缩略图和方形“＋”，可以继续追加同一动作的照片；往下为已有标签，多选或全部不选，标签末尾“＋”用于添加新标签。底部一个大“添加”，保存成功后回卡册。首次导入不要求命名，不添加额外必填字段。名字仍为可选、最多十字，编辑入口后续另定。

### 历史
按日期倒序、以本周／上周等周周期分组；行内显示星期、日期、完成项目与用时，下面用一行极小的动作截图缩略图表示本次训练。训练计划与收藏组合后续再做，不作为当前 UI 设计阻塞项。

第三版预览包含：12 张截图示意卡、默认选中 8 张、可滚动卡册与固定底部、勾选重排、添加页追加照片／标签、按周排列的示例历史。相册与相机为入口示意，不调用真实设备权限；照片和历史尚未持久保存。
